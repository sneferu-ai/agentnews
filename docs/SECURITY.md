# SECURITY.md — AgentNews security posture

Audience: an operator or reviewer evaluating AgentNews's security design.
This document explains the threat model, the controls implemented, and the
known limits of v1. For running the service see
[`OPERATIONS.md`](OPERATIONS.md); for system design see
[`ARCHITECTURE.md`](ARCHITECTURE.md); for the HTTP/CLI interface see
[`API.md`](API.md); for building and testing see
[`DEVELOPMENT.md`](DEVELOPMENT.md).

---

## 1. Authentication model

AgentNews uses **API keys** for the paid API and **no login** for the public
surface.

- **Key format:** `ak_` + 32 lowercase hex characters (128 bits of entropy).
- **Storage:** keys are SHA-256 hashed with a per-installation salt before
  being written to the `api_keys` table. The plaintext is returned **once** by
  `agentnews key create` and never recoverable. Only the first 8 characters
  (`ak_024d9…`) are stored in the clear as `key_prefix` for log/reporting
  display.
- **Transmission:** keys are sent as `X-API-Key: ak_…`. In production, TLS terminates at nginx
  (`scripts/agentnews.nginx`); the plaintext key never crosses the public
  network in the clear.
- **Validation:** `auth.validate_key` returns `(valid, reason)`. Valid keys
  are cached in-memory with a TTL. Revoked or expired keys are recognized on
  the next cache miss.
- **Admin surface:** there is **no admin HTTP endpoint**. Every
  state-mutating operation (forced imports, key management, withhold/republish,
  sample curation) is a CLI subcommand and requires `ADMIN_TOKEN` set in the
  environment. The public API cannot mutate state.
- **No sessions, cookies, OAuth, or CSRF surface.** The API is stateless; the
  HTML surface is read-only and server-rendered.

## 2. Authorization

Authorization is binary: **public** or **subscriber**. A subscriber key unlocks
`/v1/packages` and `/v1/packages/{pid}`. Every other route (catalog, sample,
verify, health, OpenAPI, HTML, feed) is public. There are no per-object
permissions, no roles, no group memberships.

The single sample slot (`is_sample=1`) is a curation state, not an
authorization state — it controls what `/v1/sample` returns, not who can see
what.

## 3. Secrets handling

| Secret | Where it lives | How it is protected |
|--------|----------------|---------------------|
| `ADMIN_TOKEN` | `.env` on the host | Filesystem permissions on `/opt/agentnews/.env` (operator responsibility); never logged. |
| API key plaintext | Shown once at `key create`, then discarded | SHA-256 + salt at rest; only the hash is persisted. |
| `LOG_SALT` | `.env` (auto-generated by `init`) | Protects IP/UA hashes in `request_log` from trivial rainbow-table reversal. |
| TLS private key | OS key/cert store | Managed by the operator; not referenced by the application. |

**Secret rotation:**

- `ADMIN_TOKEN`: change the value in `.env` and restart the service. No
  downstream state depends on the old token.
- API keys: `key revoke <prefix>` the old one, `key create` a new one, hand it
  to the subscriber. The cache TTL means revocation takes effect within
  seconds.
- `LOG_SALT`: changing the salt invalidates the ability to correlate old
  `request_log` IP/UA hashes with new ones — by design. Do not rotate it
  unless you accept that trade-off.

## 4. Input validation

- **Path parameters** (`pid`, `slug`, static-file names) are sanitized through
  shared filename/path safety primitives. The static-file route refuses
  traversal (`..`, absolute paths) and whitelists extensions.
- **Query parameters** (`limit`, `offset`) are bounded: `1 ≤ limit ≤ 100`,
  `offset ≥ 0`. Out-of-range values return 422.
- **Import payloads** are parsed from Sneferu run directories. `ingest.py`
  validates required files exist and are readable, parses YAML front-matter
  defensively, and refuses runs with missing `signature.json` or
  `artifact.md`. Citation excerpts are bounded by `EXCERPT_LIMIT_WORDS`.
- **Markdown/HTML rendering** uses a stdlib-only allowlist sanitizer
  (`render.py`). Allowed tags: `p, h1-h6, ul, ol, li, a, strong, em, code, pre,
  blockquote`. Allowed attributes: `a[href], a[rel]`. External links gain
  `rel="noopener noreferrer"`. `script`, `iframe`, `style`, `on*` attributes,
  and `javascript:` URLs are stripped.
- **Error envelopes** never include stack traces, internal file paths, or SQL
  fragments — only a flat `{code, message}`.

## 5. Transport security

- **TLS terminates at nginx.** The ASGI process listens on `127.0.0.1:8000`
  and is never directly exposed. `Strict-Transport-Security` is sent on every
  response.
- **`PUBLIC_URL` must be `https://`** unless `AGENTNEWS_ALLOW_INSECURE=true`
  (local dev only; prints a warning at startup).
- **`Referrer-Policy: no-referrer`** prevents leaking URLs (which contain
  package ids) to linked third-party sites.
- There is no WebSocket surface. All routes are HTTP/1.1 over keepalive.

## 6. Rate limiting and abuse prevention

- **Per-key:** `RATE_LIMIT_PER_DAY` (default 100) + `BURST_ALLOWANCE` (default
  20) on a rolling 24h window. A 429 response includes `Retry-After`.
- **Per-IP:** 60/day on `/v1/catalog`, 10/day on `/v1/sample`.
- **Per-User-Agent hash:** 10/day on `/v1/sample` (a second axis to complicate
  IP rotation).
- **State:** in-memory deques, warmed from `request_log` on startup. A restart
  resets burst state but preserves the 24h history.
- **Client IP:** read from the socket peer by default. When
  `TRUST_PROXY_HEADERS=true`, the app reads the last `X-Forwarded-For` hop.
  Set this **only** behind a trusted nginx proxy you control; otherwise the
  header is client-supplied and trivially spoofable.

## 7. Data protection

- **PII in logs:** the `request_log` table stores **hashed** IP and
  User-Agent values (salted with `LOG_SALT`), never the raw values. The key
  is stored as `key_prefix` only. No request/response bodies are logged.
- **At rest:** the SQLite database file is unencrypted. Filesystem-level
  encryption (LUKS, FileVault) is the operator's responsibility.
- **Backups:** `agentnews backup` produces a plain SQLite copy; protect it
  with the same filesystem permissions as the live DB.
- **Retention:** `agentnews purge-logs --days N` deletes `request_log` rows
  older than N days (default 30). Package data is retained indefinitely
  (withdrawn bundles are `withheld`, not deleted).

## 8. Dependency posture

- **Runtime dependencies:** FastAPI, Starlette, Uvicorn, Pydantic v2, Jinja2,
  httpx (URL verification), PyYAML. All are pinned in `setup.py` with
  lower bounds; run `pip-audit` or your scanner of choice against the
  installed venv.
- **No client JavaScript** means the client attack surface is effectively the
  CSP. `script-src 'none'` is enforced in the `Content-Security-Policy`.
- **`markdown` and `bleach` are not assumed available.** `render.py` ships a
  stdlib-only renderer and sanitizer. This narrows Markdown support (no
  tables, no fenced code language hints) but removes two dependencies from the
  render hot path.

## 9. Known limits of v1

These are not vulnerabilities by themselves but are limits the operator must
understand:

1. **No horizontal scaling.** One process, one SQLite file, one host. WAL +
   `busy_timeout` + `retry_on_lock` handle the observed contention; do not
   run multiple ASGI workers against the same DB file.
2. **In-memory rate limiting.** State is per-process. A restart resets burst
   windows (the 24h history is rebuilt from `request_log`).
3. **No audit log of admin actions.** `withhold`, `republish`, `--force`, and
   key management write to the DB and to stdout but not to a dedicated
   append-only audit trail. `request_log` captures API reads only. Operator
   shell history and the systemd journal are the current forensic surface.
4. **No row-level encryption.** The DB file is plaintext. Use
   filesystem-level encryption.
5. **URL verification is advisory at import time.** A citation recorded as
   `verified: 1` was reachable at import time; it may go offline later. The
   `verify` endpoint checks the bundle's content hash, not citation liveness.
6. **No SSRF hardening beyond the HTTP client defaults.** `filter.py` verifies
   citation URLs via `httpx`; it does not block private IP ranges. If you
   import untrusted run directories, review `filter.py` before enabling URL
   verification against arbitrary external URLs.
7. **No SAST/DAST pipeline is wired in.** The repo ships unit tests and a
   smoke harness; it does not ship a static-analysis gate. Run `pip-audit`,
   `bandit`, or your scanner of choice in your CI.
