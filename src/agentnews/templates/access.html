What you receive

  • A versioned JSON REST API (/v1/packages, /v1/packages/{id}, /v1/packages/{id}/verify) with stable schema versions.
  • An Atom feed (/feed.xml) of the 20 most recently published bundles.
  • Per-bundle convergence certificate: model-family count, cross-vendor flag, degraded-mode flag, quality score, content hash.
  • Citation-verification state per reference (link resolved / access restricted / link failed / wrong paper / not checked) so your agent knows what it can trust. For arXiv references, "resolved" also means the page names the paper the citation claims.
  • Reuse license terms (attribution required, republish excerpts up to 300 words, derivatives and commercial use permitted).
